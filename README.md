# Пульс рынка

Ежедневный срез российского рынка: индекс МосБиржи, гособлигации, юань и акции финансового сектора. Данные приходят из открытого API Московской биржи, а GitHub Actions каждую ночь сам скачивает новые торги, пересчитывает показатели и обновляет этот README и [веб-страницу](https://antonshkelll.github.io/ru-market-pulse/).

Руками здесь ничего не обновляется: таблица и графики ниже собраны роботом.

## Как это работает

```
MOEX ISS API ──► pulse/iss.py ──► data/*.csv ──► pulse/build.py ──► README.md, charts/*.png, docs/data.json
     ▲                (история, пагинация)       (KPI, графики)                       │
     └──────────────── GitHub Actions, каждый день в 00:15 МСК ◄──────────────────────┘
```

- **Сбор.** [`pulse/iss.py`](pulse/iss.py) забирает историю закрытий из [MOEX ISS](https://iss.moex.com/iss/reference/) постранично. Повторные запуски докачивают только последние дни.
- **Хранение.** История лежит в `data/*.csv` прямо в репозитории, поэтому каждое изменение видно в истории коммитов.
- **Показатели.** Изменение за день, за 30 дней и с начала года. Месяц считается от последнего закрытия не позже, чем 30 дней назад, так что выходные и праздники не ломают расчёт.
- **Отказоустойчивость.** Если биржа не ответила по какой-то бумаге, остаются прошлые данные, а сборка не падает. Workflow завершается ошибкой, только если не удалось получить ни одного ряда.
- **Веб-страница.** [`docs/index.html`](docs/index.html) — статическая страница без сборщиков: Chart.js читает `docs/data.json`.

## Что отслеживается

| Ряд | Код на бирже | Зачем смотреть |
|---|---|---|
| Индекс МосБиржи | IMOEX | общее настроение рынка акций |
| Индекс гособлигаций | RGBI | растёт, когда рынок ждёт снижения ключевой ставки |
| Юань к рублю | CNYRUB_TOM | основная валютная пара биржи после остановки торгов долларом |
| Сбербанк, Т-Технологии, ВТБ, Мосбиржа | SBER, T, VTBR, MOEX | финансовый сектор: банки и сама биржа |

Добавить бумагу — одна строка в списке `SERIES` в [`pulse/iss.py`](pulse/iss.py).

## Запуск у себя

Нужен Python 3.10+ и доступ к iss.moex.com.

```bash
git clone https://github.com/antonshkelll/ru-market-pulse.git
cd ru-market-pulse
python3 -m venv .venv && source .venv/bin/activate      # Windows: py -m venv .venv; .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m pulse.build          # скачать данные и пересобрать всё
python -m pulse.build --offline  # пересобрать из уже скачанных data/*.csv
pytest -q                      # тесты на поддельном API: пагинация, сбои сети, расчёт KPI
```

Веб-страницу можно открыть локально: `python -m http.server -d docs 8000` → http://localhost:8000.

### Свой экземпляр с автообновлением

1. Fork этого репозитория.
2. Actions → включить workflows → «Update data» → Run workflow (первый запуск скачает историю с 2024 года).
3. Settings → Pages → Deploy from a branch → `main` / `docs`, и через минуту страница будет по адресу `https://<ваш-логин>.github.io/ru-market-pulse/`.

## Ограничения

- Цены закрытия не корректируются на дивиденды и сплиты. Например, у ВТБ в 2024 году была консолидация акций, поэтому длинную историю VTBR нельзя сравнивать «в лоб».
- Это наблюдательный дашборд, а не торговая система и не инвестиционная рекомендация.
